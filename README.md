# QUANTAVIA — Quantum Mechanics Visualized

A responsive, client-side educational quantum mechanics visualization prototype.

## Run locally
Open `index.html` in a modern browser. No build step or server is required.

## GitHub Pages
Create a repository, upload `index.html` and `README.md`, then enable Settings → Pages → Deploy from branch → main → /(root).

The site is responsive for mobile and desktop. It includes interactive visualizations for a 1D box, finite well, harmonic oscillator, tunneling, and hydrogen states.
